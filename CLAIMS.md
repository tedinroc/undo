# Claims

Each row says what is claimed, the command that checks it, where that ran, its label, the last date it ran (UTC) and the real hash it rests on, with its chain named. A row or a part of a row that has not run says **not yet run**. `./verify.sh` prints the same claim numbers.

Re-run: `./verify.sh` (tier A then B), `./verify.sh A`, `./verify.sh B`, `./demo.sh`. Sandbox rows: `scripts/build.sh`, then `UNDO_TEST_FILTER=<test> scripts/protocol-check.sh --test <file>` with `NEAR_SANDBOX_BIN_PATH` set; the whole suite is `scripts/protocol-check.sh`.

Labels: `[live-testnet]` NEAR testnet. `[live-mutinynet]` Mutinynet, a Bitcoin signet with test coins. `[replay]` a real hash fetched again and re-verified. `[consensus-lib]` libbitcoinconsensus, through rust-bitcoin. `[regtest]` a local bitcoind with standard relay policy. `[mock-signer]` a local NEAR node running the real wasm, with a mock signer in place of Chain Signatures. `[unit]` pure Rust, no chain. `[static]` a read of the source. No row is `[live-mainnet]`.

Wasm builds named below: **G1/G2 build**, sha256 `4eafca45…` (NEAR testnet code hash `6JAGfdMuvVhxszbTT2VabYD39VadHc8txiWLqBdU6iE1`), the earlier build that ran live; **11/1 build**, sha256 `1f0f7860…`, the last full sandbox run in `docs/measurements.md`; **current build**, sha256 `4632075a…`, the one the local stage ran on 2026-11-06. No build of this tree is deployed on testnet yet: `deploy/testnet.json` is a placeholder.

## Self-test

`./demo.sh` on a local stage (local NEAR node with the current build and a mock signer, regtest bitcoind, the relay handler from `site/functions/_relay`), 2026-11-06, `[mock-signer]`: a vault made through the relay and active; a proposal to a new address waiting 5:00 on the contract's clock; a passkey cancel; a send to the vault's own address executed after 1:00 and signed; the contract's final transaction accepted by libbitcoinconsensus for the made-up coin and refused for a wrong value. Five PASS lines in 67 s. Against NEAR testnet: **not yet run** (nothing deployed).

## Who wrote the checks

Independent of this repository: libbitcoinconsensus (through rust-bitcoin's `bitcoinconsensus` feature), bitcoind on regtest, the Mutinynet node's answers, the NEAR testnet signer's own views and signatures. Every test, property and driver was written in this repository by the author with AI coding assistance (Claude). The sandbox's mock signer stands in for Chain Signatures and is labelled `[mock-signer]` wherever it is used.
